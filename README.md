# 90 Seconds: Emotion Check-in (iOS)

SwiftUI app for a quick, 90-second emotional check-in.

## Features

- Choose how you feel from a set of emotions
- Short session, then optionally write down a "micro-win"
- History of your last 10 sessions, stored on the device
- Help screen and haptic feedback

## Tech

Swift, SwiftUI, Combine, MVVM architecture (`AppViewModel`).

## Running

Open the project in Xcode and run it on an iPhone simulator or device.
